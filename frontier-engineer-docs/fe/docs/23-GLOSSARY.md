# Part 23 — Glossary (supplementary)

| Term | Meaning |
| --- | --- |
| Agent | A role with a mission, responsibilities, boundaries, and deliverables (e.g. Architect) |
| Skill | A reusable procedure/expertise package, stored as `SKILL.md` plus optional references |
| Rule | A persistent standard agents must follow; concise and non-duplicating |
| Coordinator | The primary agent (`frontier-engineer`) that classifies, plans, delegates, and verifies |
| Specialist | One of the five focused agents under the coordinator |
| MCP | Model Context Protocol — a standard for exposing external tools to agents |
| Hook | An event-driven safeguard; only used if officially supported by Antigravity |
| ADR | Architecture Decision Record — a short record of a technical decision and its consequences |
| Project profile | A Project Intelligence Report summarizing a repository's verified facts |
| Progressive disclosure | Loading only the context needed (e.g. concise profiles, referenced files on demand) |
| Verified fact | Confirmed from source files, configuration, or executed output |
| Inferred observation | A conclusion drawn from evidence but not directly confirmed |
| Advisory / Assisted / Verification | The three workflow modes (policy, not native APIs) |
| Quality gate | A configurable requirement that must pass before work is called complete |
