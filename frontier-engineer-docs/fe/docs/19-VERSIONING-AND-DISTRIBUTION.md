# Part 19 — Versioning and Distribution

Use semantic versioning: `MAJOR.MINOR.PATCH`

- `1.0.0` — First stable release
- `1.1.0` — New capabilities
- `1.1.1` — Bug fixes
- `2.0.0` — Major architectural changes

## 19.1 Release plan

| Version | Focus |
| --- | --- |
| 1.0.0 | Core agents, skills, rules, integrations |
| 1.1.0 | Project intelligence and engineering memory |
| 1.2.0 | Improved debugging and automated verification |
| 1.3.0 | Advanced evaluation and reporting |
| 2.0.0 | Advanced orchestration and additional supported capabilities |

## 19.2 Distribution

Potential methods:

- GitHub repository
- GitHub Releases
- ZIP package
- Official Antigravity plugin marketplace, if supported and approved

Do not claim marketplace availability until the plugin has actually been accepted or published.

## 19.3 Maintenance

Maintain: dependency updates, agent instruction improvements, skill improvements, security fixes, compatibility updates, documentation updates, regression tests.
